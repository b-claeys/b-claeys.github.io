BROOKLYN CLAEYS PORTFOLIO — STATIC SITE

This folder is the deployment-ready static copy of the supplied portfolio.
No build step, package manager, server-side code, or framework is required.

ENTRY POINT
  index.html

DEPLOYMENT
  Upload the CONTENTS of this folder to the root of a static web host.
  Keep the directory structure and filename capitalization unchanged.

  Suitable static-host workflow:
  - GitHub Pages: place these files at the publishing root of the Pages branch/folder.
  - Netlify / Cloudflare Pages: deploy this folder as the static site output directory.

IMPORTANT
  The exact supplied media has been preserved rather than recompressed. The site is
  approximately 343 MB and includes a chamber MP4 that is approximately 118 MB, so
  confirm the individual-file limits of the host you choose before uploading.

CONTACT FORM
  The existing contact behavior is preserved. It uses the visitor's local email
  client rather than a server-side form service.

See DEPLOYMENT_AUDIT.txt for the path/link audit and the exact source changes.
